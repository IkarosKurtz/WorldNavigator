WorldNavigator documentation
============================

WorldNavigator is a tool designed to facilitate the creation of navigable virtual worlds.
With this framework, you can define locations, connections between them, interactive objects, and specific rules for your virtual world.

Main features:
--------------

* Creation of JSON-based virtual worlds
* Easy integration with Ren'Py
* Navigation system between locations
* Event and observer management
* Simulation of weather conditions
* Web editor for creating and editing worlds
